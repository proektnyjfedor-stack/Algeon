# Algeon

Математический тренажёр для 1–11 классов: 1649 заданий, 116 тем, теория, практика и 17 достижений. Основное приложение написано на Flutter Web. Страница о проекте находится в `web_landing/` и включается в сборку по адресу `/about/`.

## Что работает

- Выбор класса, темы и тренировки, проверка ответов, объяснения, статистика и награды.
- Русский и английский интерфейс, светлая, тёмная и системная тема.
- Локальное сохранение прогресса в браузере.
- Возобновление незаконченного урока: задание, введённый ответ, результаты и время. Изменения ввода сохраняются с задержкой 250 мс, время — каждые 10 секунд.
- Резервная копия профиля, решённых задач, наград и настроек: **Профиль → Твой прогресс → Сохранить и восстановить**. Импорт проверяет формат и требует подтверждения перед заменой текущих данных.

Облачная синхронизация, вход в аккаунт и AI-помощник пока не подключены. Прогресс привязан к браузеру и адресу сайта; очистка данных браузера удаляет его. Для переноса на другое устройство используй резервную копию. Незаконченный урок в копию не включается.

## Требования

Flutter 3.41.7 используется в CI; минимальные версии проекта — Flutter 3.38.4 и Dart 3.10.3. Для локального сервера нужен Python 3.

## Разработка

```bash
flutter pub get
flutter run -d chrome
```

## Проверка

```bash
flutter analyze --no-pub
bash tool/test_local.sh --no-pub --reporter expanded
```

Скрипт тестов на macOS использует установленные Command Line Tools, без изменения глобальных настроек Xcode. Проверяются ответы, каталог заданий, параллельные записи прогресса, смена учебных дней, резервные копии, история браузера, незаконченные уроки и пользовательские сценарии на разных ширинах экрана.

## Сборка и просмотр

```bash
bash tool/build_web.sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory build/web
```

Приложение: http://127.0.0.1:8765. Страница о проекте: http://127.0.0.1:8765/about/.

Сборка включает CanvasKit с собственного сервера, чтобы загрузка не зависела от gstatic. Если локальный Flutter сообщает об отсутствующем `const_finder.dart.snapshot`, можно собрать с `bash tool/build_web.sh --no-tree-shake-icons`. Это оставляет полный шрифт иконок. `bash tool/preview.sh` использует этот совместимый вариант, собирает сайт и запускает сервер. Ctrl+C останавливает сервер.

## Публикация

Firebase Hosting использует `build/web` и проект `algeon-66295`. Workflow сначала выполняет анализ, тесты и сборку, затем публикует сайт при push в main. Для этого нужны настроенные секреты GitHub. Локальное улучшение и просмотр сами по себе ничего не публикуют.

## Структура

- `lib/` — приложение, каталог, сервисы и экраны.
- `web/` — загрузчик Flutter и web manifest.
- `web_landing/` — страница о проекте.
- `test/` — проверки поведения и регрессий.
- `tool/` — сборка, тесты и локальный просмотр.
- `functions/` — существующие заготовки Firebase Functions.

## Экзамены

Вкладка `/exams`: по 10 полных тренировочных вариантов ОГЭ, ЕГЭ база и ЕГЭ профиль. Перед каждым заданием показан метод решения. Краткие ответы проверяются автоматически, развёрнутые — по образцу из источника. Позиция, черновики и результаты сохраняются локально и включены в резервную копию профиля. Сведения об источниках и статусе проектов ФИПИ 2027: [EXAMS-SOURCES.md](EXAMS-SOURCES.md).

## Акцентный цвет

В настройках профиля доступны семь оттенков и свой цвет через HEX/RGB. Цвет применяется к навигации, кнопкам, полям ввода и выделениям; оттенок адаптируется для читаемости в светлой и тёмной теме. Настройка сохраняется локально и входит в резервную копию профиля.


## Подготовка и повторение

В «Практике» появились личный план, журнал ошибок, статистика тем и необязательная диагностика из 9 заданий. План учитывает выбранный экзамен/класс, цель, дату и ежедневную нагрузку. Ежедневная подборка начинает с просроченных повторений и включает разные темы.

После ошибки исправление назначает повтор через 1 день, затем через 3 и 7 дней. Раннее повторение не ускоряет зачёт. Новая ошибка возвращает задание в начало цикла. Подробная история собирается только из новых попыток; старые ошибки не выводятся из общих счётчиков.

На карточке каждого варианта есть «Пробный экзамен»: 235 минут для ОГЭ/профиля и 180 для базы, по проектам спецификаций ФИПИ 2027 из EXAMS-SOURCES.md. Абсолютный срок и ответы сохраняются локально; обновление страницы не перезапускает таймер. Теория и решения скрыты до завершения. Краткие ответы проверяются автоматически; развёрнутые решения требуют сверки с источником. Официальные баллы не выставляются. В режиме обучения доступна явно обозначенная самооценка развёрнутых решений.

Математический ввод поддерживает создание дроби через числитель/знаменатель, степени, корни и скобки, выделение/замену текста и предпросмотр. Это средство записи ответа, не калькулятор. История, план, диагностика и текущие пробные экзамены входят в экспорт/импорт резервной копии и сбрасываются вместе с учебным прогрессом.

Проверки новых сценариев: `test/learning_features_test.dart` — интервалы повторения, защита от дублирования, сбалансированный план, диагностика с продолжением, таймер после перезагрузки, завершение по времени/вручную, скрытие решений, резервная копия, математический ввод и узкий экран.

## Поиск, закладки и наглядные примеры

На главной доступен поиск по темам и условиям заданий с фильтром по классу. Задания, теорию и экзаменационные задания можно сохранять кнопкой закладки; они входят в резервную копию. Сброс учебного прогресса сохраняет закладки, полный сброс удаляет их.

Выбор варианта ответа подтверждается кнопкой «Проверить». Подсказки раскрываются постепенно; открытие разбора не засчитывается как правильное решение. Для числовых выражений и поддерживаемых линейных уравнений создаются конкретные шаги решения. Общие советы больше не выдаются за подробный разбор. В теории доступны интерактивные примеры дробей, синусоиды, прямой, параболы и прямоугольного треугольника.

Проверки: 57 тестов, отображение 1649 заданий; независимый расчёт 366 числовых выражений, линейных уравнений и задач на доли, проценты, делители и целочисленные корни. Эта проверка не является полной математической экспертизой всех условий и развёрнутых решений.
